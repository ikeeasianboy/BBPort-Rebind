Controller Remapper

Remap your controller using Bloodborne action names instead of generic PlayStation button labels. This page runs in your browser and never uploads your files. Your selections are saved in this browser; download the INI to carry them to the game or another PC.

Prototype limits: The action names describe what Bloodborne does with each PlayStation-style input. This editor remaps digital buttons and triggers only. Analog-stick directions are shown below for reference but are not remappable yet. The current runtime also treats View/Back and the touchpad as one touchpad action, so left and right touchpad actions cannot be assigned separately. Restart the game after replacing the INI file.

Analog controls · reference only

Left stickMove the hunter; hold Circle while moving to sprint
GAME ACTIONMove character
Right stickMove the camera
GAME ACTIONControl camera
Using standard default mappings. Load your existing INI first to keep its current A/B swap.

The left column is the physical controller input; the dropdown is the Bloodborne action it will trigger. The saved INI keeps the runtime tokens (such as south=circle) while this editor displays readable action names. SDL calls the bottom, right, left, and top face buttons south, east, west, and north.

To apply your file, move the downloaded controller-remap.ini beside your installed Bloodborne.exe, replace the previous INI, then start the game with Launch Controller Test.bat. Keep a backup of the working INI.
